YouTube 需要登录状态才能解析和下载视频。Cookies 会定期轮换，失效后重新导出即可。

方式一：插件导出（推荐）

1. 安装 Get cookies.txt LOCALLY（Chrome/Edge）
2. 打开 youtube.com 并登录账号
3. 点插件图标 → Export → 保存文件
4. 点下方按钮上传

方式二：从浏览器直接导出

⚠️ 操作时需完全关闭浏览器，否则数据库被占用会失败。
